# Controller reference

The user requested a code recreation of the supplied DG3.webp: charcoal face, black enclosure and grips, yellow OLED, four round cream keys and a covered USB socket. The reference is retained unchanged; the runtime controller is native SVG/CSS with real buttons and a canvas display.

Reading this as: a local hardware simulator with only three bare LED signs and the controller. ENERGY 1 / RHYTHM 2 / MOTION 1.

The case gradients describe metal and moulded plastic from the reference. The dots represent actual addressable output pixels. Round keys match the hardware rather than a web component template. Yellow/amber belongs to emitted text; the surrounding page is dark and neutral for contrast. No workbench, labels, navigation or decorative panels surround the hardware.

The driver entry display and field editors are rendered from engine state. Pending values and accepted values have different positions, and passenger output only changes on acceptance. Visible focus and accessible live screen descriptions accompany the four physical controls.
